# 事件循环

## 整体架构


```
Call Stack（调用栈）
      │
      ▼
Web APIs / Node APIs
      │
      ▼
Task Queue（任务队列）
 ├─ Microtask Queue
 │   Promise.then
 │   queueMicrotask
 │   MutationObserver
 │
 └─ Macrotask Queue
     setTimeout
     setInterval
     I/O
     UI events
```
执行流程：

```
1 执行同步代码（Call Stack）
2 清空 Microtask Queue
3 执行一个 Macrotask
4 再清空 Microtask
5 进入下一轮 Event Loop
```

常见宏任务：

```
setTimeout
setInterval
setImmediate (Node)
I/O
UI rendering
script
```

常见微任务：

```
Promise.then
Promise.catch
Promise.finally
queueMicrotask
MutationObserver
process.nextTick(Node)
```

因此浏览器中的事件循环：

```javascript
执行 script（宏任务）

↓
清空 microtask

↓
渲染 UI

↓
执行下一个 macrotask
```

Node循环

```javascript
timers
↓
pending callbacks
↓
idle / prepare
↓
poll
↓
check
↓
close callbacks
```

| 特性            | 浏览器            | Node       |
| ------------- | -------------- | ---------- |
| 微任务执行         | 每个 macrotask 后 | 每个 phase 后 |
| nextTick      | 不存在            | 优先级最高      |
| setImmediate  | 不支持            | check 阶段   |
| UI 渲染         | 存在             | 不存在        |
| Event Loop 实现 | 浏览器引擎          | libuv      |


```javascript
console.log(1)

setTimeout(() => {
  console.log(2)
})

Promise.resolve().then(() => {
  console.log(3)
})

console.log(4)

// 1 4 3 2
```

```javascript
setTimeout(() => console.log(1))

Promise.resolve()
  .then(() => console.log(2))
  .then(() => console.log(3))

console.log(4)

// 4 2 3 1
```

```javascript
Promise.resolve()
  .then(() => {
    console.log(1)
  })
  .then(() => {
    console.log(2)
  })

Promise.resolve()
  .then(() => {
    console.log(3)
  })

// 1 3 2
// then 链不会一次性进入 microtask. 每个 then 执行完才会注册下一个 then
```

```javascript
console.log(1)

setTimeout(() => {
  console.log(2)

  Promise.resolve().then(() => console.log(3))
})

Promise.resolve().then(() => {
  console.log(4)
})

console.log(5)

// 1 5 4 2 3
```

```javascript
async function foo() {
  console.log(1)
  await bar() // await 本质是 Promise.then
  console.log(2)
}

async function bar() {
  console.log(3)
}

console.log(4)

setTimeout(() => console.log(5))

foo()

Promise.resolve().then(() => console.log(6))

console.log(7)
```
