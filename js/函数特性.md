# 函数特性

## 高阶函数

高阶函数 = 满足以下任一条件

1️⃣ 接收函数作为参数
2️⃣ 返回函数

```javascript
function foo(fn) {
  fn()
}

function bar() {
  console.log("hello")
}

foo(bar)
```

## 柯里化（Currying）

柯里化：把一个多参数函数转换成多个单参数函数

```javascript
f(a,b,c)

↓

f(a)(b)(c)

function add(a) {
  return function(b) {
    return function(c) {
      return a + b + c
    }
  }
}

add(1)(2)(3)
```

## 偏函数（Partial Function）

偏函数 = 固定部分参数

```javascript
function add(a, b, c) {
  return a + b + c
}

function partial(fn, ...args) {
  return function(...rest) {
    return fn(...args, ...rest)
  }
}

const add5 = partial(add, 2, 3)

add5(10)
```

|    | 柯里化     | 偏函数    |
| -- | ------- | ------ |
| 参数 | 逐个传入    | 一次固定   |
| 调用 | f(a)(b) | f(a,b) |


## 纯函数（Pure Function）

纯函数必须满足：

1、 输入决定输出，同样的输入一定是同样的输出
2、没有副作用（比如不修改外部变量）

常见的副作用：
```
修改全局变量
DOM 操作
console.log
HTTP 请求
localStorage
Math.random
Date.now
```




## 经典题

### 实现一个 map
```javascript
function myMap(arr, fn) {
  const result = []

  for (let i = 0; i < arr.length; i++) {
    result.push(fn(arr[i], i, arr))
  }

  return result
}
```
