# 对象属性机制

JS对象中属性分两类：

1️⃣ 数据属性（Data Property）
2️⃣ 访问器属性（Accessor Property）

```
Property Descriptor
        │
 ┌──────┴──────┐
 │             │
数据属性      访问器属性
 │             │
value         get
writable      set
enumerable    enumerable
configurable  configurable
```

## 数据属性（Data Property）
```javascript
const obj = {
  name: "Tom"
}

{
  value: "Tom",
  writable: true,
  enumerable: true,
  configurable: true
}
```
| 属性           | 作用            |
| ------------ | ------------- |
| value        | 属性值           |
| writable     | 是否可修改         |
| enumerable   | 是否可枚举         |
| configurable | 是否可删除 / 修改描述符 |

## 访问器属性（Accessor Property）

访问器属性 没有 value，而是通过函数控制。
```javascript
const obj = {
  get name() {
    return this._name
  },
  set name(v) {
    this._name = v
  }
}

{
  get: function(){},
  set: function(){},
  enumerable: true,
  configurable: true
}
```

## 核心属性

###  writable（可写）

```javascript
Object.defineProperty(obj, "x", {
  value: 1,
  writable: false
})

obj.x = 2 // 实际上改不了，还是 1
```

### enumerable（可枚举）
控制是否能被遍历：
```javascript
Object.defineProperty(obj, "x", {
  value: 1,
  enumerable: false
})

Object.keys(obj) // []
for...in // []
```

### configurable（可配置）
决定是否可以：

1️⃣ 删除属性
2️⃣ 修改属性描述符
```javascript
Object.defineProperty(obj, "x", {
  value: 1,
  configurable: false
})

delete obj.x // false
```

vue2 就是使用 `Object.defineProperty` 进行响应式编程。

## 经典题

```javascript
const obj = {}

Object.defineProperty(obj, "age", {
  value: 18
  // 因为默认 writable = false
  // enumerable: false
  // configurable: false
})

obj.age = 20
console.log(obj.age) // 18
```


```javascript
const proto = { a: 1 }

const obj = Object.create(proto)

obj.b = 2

// 此时 obj.__proto__ = proto;
"a" in obj // true, 在原型上
obj.hasOwnProperty("a") // false，只会检测自身属性
Object.keys(obj) // ["b"]，自身 + 可枚举属性
```

| 方法               | 是否查原型链 | 是否只看 enumerable | 返回什么    |
| ---------------- | ------ | --------------- | ------- |
| `in`             | ✅ 查    | ❌ 不限制           | boolean |
| `hasOwnProperty` | ❌ 不查   | ❌ 不限制           | boolean |
| `for...in`       | ✅ 查    | ✅ 只 enumerable  | key     |
| `Object.keys`    | ❌ 不查   | ✅ 只 enumerable  | key 数组  |

总结:
> in                → 判断属性是否存在
> hasOwnProperty    → 判断是否自身属性
> for...in          → 枚举属性（含原型）
> Object.keys       → 枚举自身属性


```javascript
const obj = {}

Object.defineProperty(obj, "x", {
  value: 1,
  enumerable: false
})

console.log(Object.keys(obj)) // []
```

```javascript
const obj = {}

Object.defineProperty(obj, "x", {
  value: 1,
  configurable: false
})

delete obj.x

console.log(obj.x) // 1
```


```javascript
const obj = {
  get x() {
    return 10
  }
}

obj.x = 20

console.log(obj.x) // 10
```

configurable = false
不能修改 configurable
但可以修改 writable -> false

```javascript
const obj = {}

Object.defineProperty(obj, "x", {
  value: 1,
  writable: true,
  configurable: false
})

obj.x = 2

Object.defineProperty(obj, "x", {
  writable: false
})

console.log(obj.x) // 2
```

```javascript
const obj = { a:1 }

Object.defineProperty(obj, "b", {
  value:2
})

for (let key in obj) {
  console.log(key) // a
}
```
