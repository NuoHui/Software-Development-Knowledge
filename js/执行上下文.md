# 执行上下文

```javascript
// 执行上下文
ExecutionContext {
  // 词法环境
  LexicalEnvironment
  VariableEnvironment
  ThisBinding
}
```

| 字段                  | 作用                 |
| ------------------- | ------------------ |
| LexicalEnvironment  | let / const / 块作用域 |
| VariableEnvironment | var / function     |
| ThisBinding         | this 指向            |

```javascript
// 词法环境
LexicalEnvironment {
  // 存储变量
  EnvironmentRecord
  // 指向外层作用域
  Outer
}
```

环境记录：真正存储变量的地方，不同作用域使用不同类型的 EnvironmentRecord。
EnvironmentRecord

| 类型                             | 用途            |
| ------------------------------ | ------------- |
| Declarative Environment Record | let / const   |
| Object Environment Record      | with / global |
| Function Environment Record    | 函数            |
