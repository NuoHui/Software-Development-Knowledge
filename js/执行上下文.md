# 执行上下文

```javascript
// 执行上下文
ExecutionContext {
  // 词法环境
  LexicalEnvironment
  VariableEnvironment
  ThisBinding
}
```

| 字段                  | 作用                 |
| ------------------- | ------------------ |
| LexicalEnvironment  | let / const / 块作用域 |
| VariableEnvironment | var / function     |
| ThisBinding         | this 指向            |

```javascript
// 词法环境
LexicalEnvironment {
  // 存储变量
  EnvironmentRecord
  // 指向外层作用域
  Outer
}
```

环境记录：真正存储变量的地方，不同作用域使用不同类型的 EnvironmentRecord。
EnvironmentRecord

| 类型                             | 用途            |
| ------------------------------ | ------------- |
| Declarative Environment Record | let / const   |
| Object Environment Record      | with / global |
| Function Environment Record    | 函数            |


```javascript
const a = { x: 1 }

a.x = 2

console.log(a.x) // 2 引用不可变, 对象内容可变
```

```javascript
var a = 10

function foo() {
  var a = 20

  function bar() {
    console.log(a) // 20
  }

  return bar
}

var fn = foo()
fn() // 20
```

```javascript
var a = 1

function foo() {
  console.log(a) // 1
}

function bar() {
  var a = 2
  foo()
}

bar()
```

```javascript
var a = 1

function foo() {
  console.log(a) // function a() {} 函数声明优先提升

  var a = 2

  function a() {}

  console.log(a) // 2 覆盖赋值
}

foo()
```
