# 模块化

## 进化历史


```
全局 script
↓
AMD (RequireJS)
↓
CommonJS (Node)
↓
ES Module (ESM)
```
目前主流：

浏览器 / 工程化：ES Module
Node：CommonJS + ESM


| 特性           | CommonJS       | ESM          |
| ------------ | -------------- | ------------ |
| 加载时机         | 运行时            | 编译时          |
| 导入方式         | require        | import       |
| 导出           | module.exports | export       |
| 值类型          | 值拷贝            | live binding(引用绑定) |
| 是否同步         | 同步             | 异步           |
| tree shaking | 不支持            | 支持           |


CJS 支持运行时加载、运行时解析。
```javascript
if (condition) {
  require('./a')
}
```
