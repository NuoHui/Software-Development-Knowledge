# 模块化

## 进化历史


```
全局 script
↓
AMD (RequireJS)
↓
CommonJS (Node)
↓
ES Module (ESM)
```
目前主流：

浏览器 / 工程化：ES Module
Node：CommonJS + ESM


| 特性           | CommonJS       | ESM          |
| ------------ | -------------- | ------------ |
| 加载时机         | 运行时            | 编译时          |
| 导入方式         | require        | import       |
| 导出           | module.exports | export       |
| 值类型          | 值拷贝            | live binding(引用绑定) |
| 是否同步         | 同步             | 异步           |
| tree shaking | 不支持            | 支持           |


CJS 支持运行时加载、运行时解析。
```javascript
if (condition) {
  require('./a')
}
```

## 经典题


### CommonJS 与 ESM 最大区别是什么？

CommonJS 是运行时加载。
ESM 是编译时加载。

ESM 构建静态依赖图
支持 tree-shaking。

### ESM 引用绑定


```javascript
// a.js
export let count = 0

setTimeout(() => {
  count++
}, 1000)
```

```javascript
// b.js
import { count } from './a'

setTimeout(() => {
  console.log(count) // 1， ESM 是 live binding，不是值拷贝。
}, 2000)
```

### CJS 值拷贝


```javascript
// CommonJS
exports.count = 0

setTimeout(() => {
  exports.count++
}, 1000)
```
```javascript
const { count } = require('./a')

setTimeout(() => {
  console.log(count) // 0 解构时发生值拷贝
}, 2000)
```
### 循环依赖

```javascript
// a.js
exports.done = false
const b = require('./b')
console.log(b.done)
exports.done = true
```

```javascript
// b.js
exports.done = false
const a = require('./a')
console.log(a.done)
exports.done = true
```

输出：
```
false
false
```
Why：
```
CommonJS 返回：

未执行完成的 exports
```
